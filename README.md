# کنترل حجم صدا با تشخیص دست (Hand Gesture Volume Control)

این پروژه یک سیستم کنترل حجم صدای سیستم با استفاده از حرکات دست است. با کمک دوربین وب‌کم و کتابخانه MediaPipe، تعداد انگشت‌های باز را تشخیص می‌دهد و بر اساس آن حجم صدا را افزایش یا کاهش می‌دهد.

## ویژگی‌ها

- تشخیص دست در زمان واقعی با MediaPipe
- شمارش تعداد انگشت‌های باز
- **۳ انگشت** → افزایش حجم صدا
- **۱ انگشت** → کاهش حجم صدا
- نمایش تعداد انگشت‌ها و راهنما روی تصویر
- خروج با فشردن کلید `Q`

## پیش‌نیازها

- سیستم‌عامل: **Windows** (به دلیل استفاده از کتابخانه `pycaw`)
- پایتون ۳.۷ یا بالاتر
- دوربین وب‌کم

## نصب وابستگی‌ها

ابتدا کتابخانه‌های مورد نیاز را نصب کنید:

```bash
pip install opencv-python mediapipe pycaw comtypes
```

## نحوه اجرا

```bash
python app.py
```

پس از اجرا، پنجره دوربین باز می‌شود. دست خود را در مقابل دوربین قرار دهید:

| تعداد انگشت | عملکرد          |
|-------------|-----------------|
| ۳           | افزایش حجم صدا  |
| ۱           | کاهش حجم صدا    |

برای خروج، کلید `Q` را فشار دهید.

## ساختار کد

- استفاده از `MediaPipe Hands` برای تشخیص نقاط کلیدی دست
- تشخیص باز بودن هر انگشت بر اساس موقعیت نقاط landmark
- کنترل حجم صدا از طریق `pycaw` (رابط COM ویندوز)

## نکات

- نور محیط و پس‌زمینه ساده باعث تشخیص بهتر می‌شود.
- فقط یک دست در تصویر تشخیص داده می‌شود (`max_num_hands=1`).
- این برنامه فقط روی ویندوز کار می‌کند.
